# 管理者本人の運転実績

管理者・ITCも運転するため、管理権限を変更せずに表示範囲の「自分」を選べる。所属営業所・当月の初期表示、会社全体と営業所の管理画面は維持する。

- 自分：同じ会社のログインアカウントに本人対応が確認された日報のみ。氏名・点検・使用車両の登録から日報の本人対応を自動作成しない。
- 所属営業所／会社全体：既存の管理範囲。一般ユーザーは要求パラメーターを変えても本人範囲から広がらない。
- 日報の「本人の閲覧設定」で同じ会社の一般ユーザー・管理者・ITCを選べる。乗務員情報の変更で確認が無効になった場合、再確認まで本人表示から除く。アカウントの役割は変更しない。
- 本人表示では、指標・前期間比較・日別推移・根拠・CSV・比較CSV・PDF・AI入力を本人の日報に揃える。管理用の他人の同一車両運行や整備履歴を混在させない。AI入力と保存済み結果のキーは管理表示と区別する。通常GETで有料AIを実行しない。
- 本人の車両一覧と点検由来の候補は管理者・ITCのログインアカウントにも対応する。候補の任意訂正は本人表示への戻り先を保つ。候補を日報の確定運転者や集計に昇格させない。
- 範囲の切替時も対象期間・車両・比較条件を引き継ぐ。人物の絞り込みは解除し、本人表示から再び営業所・会社全体へ切り替えられる。
- 日報のない乗務員について、アカウントの存在まで否定する表示をしない。記録がある場合のみ「日報の本人対応未確認」を表示する。
