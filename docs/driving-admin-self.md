# 管理者本人の運転実績

管理者・ITCも運転するため、管理権限を変更せずに「自分の実績｜管理画面」をワンクリックで切り替えられる。所属営業所・当月の初期表示、会社全体と営業所の管理画面は維持する。

- 自分：同じ会社の本人アカウントを一意に特定できる日報を初回から自動表示する。氏名はUnicode正規化・空白差を吸収した完全一致で照合し、日報コードとログインIDの一致は要求しない。点検・使用車両・取込担当・所属を本人根拠にしない。
- 所属営業所／会社全体：既存の管理範囲。一般ユーザーは要求パラメーターを変えても本人範囲から広がらない。
- 特定できない日報だけ既存の読取確認で会社内アカウントを選択・修正・保留できる。既存の日報単位の明示設定と解除を優先し、有効な会社・システム・コード・運行日の対応を後続取込へ再利用する。乗務員情報の変更で確認が無効になった場合、再確認まで本人表示から除く。アカウントの役割は変更しない。
- 本人表示では、指標・前期間比較・日別推移・根拠・CSV・比較CSV・PDF・AI入力を本人の日報に揃える。管理用の他人の同一車両運行や整備履歴を混在させない。AI入力と保存済み結果のキーは管理表示と区別する。通常GETで有料AIを実行しない。
- 本人の車両一覧と点検由来の候補は管理者・ITCのログインアカウントにも対応する。候補の任意訂正は本人表示への戻り先を保つ。候補を日報の確定運転者や集計に昇格させない。
- 上部に「自分の実績｜管理画面」を常時表示する。本人表示では営業所選択を隠し、管理表示では会社全体・営業所を選べる。一般ユーザーには切替を表示しない。JavaScript無効でも通常のリンクとして動作する。
- 切替時も適用済みの対象期間・車両・比較条件を引き継ぐ。本人表示に管理対象の人物検索を持ち込まず、管理画面に戻ったときに直前の営業所・会社・人物検索を復元する。管理範囲の控えは同じログインセッションの会社・アカウント単位とし、初回・別アカウント・廃止営業所の場合は所属営業所へ戻る。控えは権限判定に利用しない。
- 日報のない乗務員について、アカウントの存在まで否定する表示をしない。記録があり自動で特定できない場合だけ「乗務員を特定できていません」と通常サイズの選択ボタンを表示する。

## 検証

`tests/test_driving_admin_self.py` の13件で、管理者・ITCの本人範囲、権限保持、本人設定、CSV／比較CSV／PDF、AI入力・キーの分離、対応解除、一般ユーザーの範囲拡大防止、点検候補の訂正、切替時の条件保持、管理対象への復帰、古い控えの無効化を確認。既存の日報関連147件と管理者本人表示・切替の13件、基盤・点検日付・業務・レスポンシブ・JavaScriptの検証も実施。

隔離SQLiteのブラウザーで320／390／430／768／1390pxの範囲切替・期間保持・本人集計・横はみ出しを確認。有料AIは実行しない。本番配備・実資料の本人対応・業務受入の完了を意味しない。

## 自動特定の追加仕様

新規取込では日報と自動特定の根拠を同一トランザクションに保存する。取込済み日報は同じ条件で読み取り専用に解決し、GETによるDB変更や有料AI実行をしない。同姓同名・氏名欠損・コード矛盾・古い識別ハッシュ・ロック中アカウント・解除と保留を自動特定で上書きしない。自動保存の関係も現在の会社内氏名とコードを再検証する。PR #241の社員ID一致案は使わない。
