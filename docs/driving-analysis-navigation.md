# 運転実績：営業所から個人分析へ進む導線

2026-10-28の利用者指示「営業所の分析、その下に営業所所属ドライバーが並ぶ」「どこをクリックすればよいか分からない」に対応する。正式仕様書v0.25の30～32ページを照合し、main `8fe148f` から変更する。

## 主表示

- 営業所：営業所のAI分析・運転傾向の下に所属ドライバーを常時表示する。記録なしの所属者と対象期間の異動者も既存ルールで表示する。
- 会社全体：会社全体のAI分析・運転傾向の下に営業所一覧を常時表示する。各行の「分析を見る」から営業所へ進む。全ドライバーの横断検索は通常サイズの入口で提供する。
- 個人：一覧の氏名と「分析を見る」から独立した個人分析へ進み、見出し・戻る操作・本人のAI振り返りから表示する。日別グラフの指標選択は常時見えるフォームとする。
- 主要な一覧や個人分析の入口を展開UIや補足文字に埋め込まない。数値カードは表示専用とし、クリックでしか分からない切替をなくす。

## 表示内容の切替

「分析」「日報一覧」「詳しく比較」「読取内容」の名前付きリンクを常時表示する。「詳しく比較」は管理権限がある場合だけ提供する。日報・比較・読取内容は、選択すると見出し付きの通常セクションで表示する。本人・会社・営業所・期間・車両の権限と絞り込みは従来と同じ。古い日報・比較へのアンカーも対象の表示を開ける。

表示の切替パラメーター `panel` はテンプレートの表示だけに使用する。本人特定、集計、AIの入力・キャッシュキーには混ぜず、表示内容の切替だけで有料生成やキャッシュの作り直しを行わない。JavaScript無効でも通常リンクで各表示へ進める。

折り畳みは、計算根拠、原本の定義・出典、変更履歴、必要時の候補訂正など補足に限定する。絞り込み条件は通常サイズの操作として表示する。「振り返り未記入」は日報の指導・振り返り状態であり、本人未特定とは区別する。

## 条件と戻り先

会社全体→営業所→個人へ進んでも対象期間を維持する。個人分析へは見出しから移動し、戻ると元の一覧と条件を復元する。日報詳細からも元の表示内容と行へ戻れる。前回修正の集計保留・本人の自動特定・閲覧権限は維持する。

## 検証

隔離SQLiteによる日報関連テスト、表示切替でAI入力キー・集計・会社境界が変わらない検証、主要一覧とグラフ選択がdetails内にない検証を実施。実アプリのHTMLをローカルChromiumで320／390／430／768／1390pxで操作し、明示した分析ボタン・個人表示の先頭・元一覧への復帰・日報詳細からの復帰・各表示内容・指標切替・横はみ出しを確認する。主要ボタンは共通CSSに縮められず40px以上で操作できることも確認する。

本番DB・実帳票・有料AI生成の確認は行わない。適用スクリプトは隔離worktreeでパッチ適用・テスト・コミットまでを行い、push・マージ・デプロイは行わない。
