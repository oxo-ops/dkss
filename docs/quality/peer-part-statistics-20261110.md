# 同型式車の部品別交換登録を表示

## 対象

2026-11-10 の実装照合版仕様書 §07・K63 にある同型式比較のうち、既存集計の未表示部分を追加する。基準は main `0b4199d246390f09396ed0e8830bd7dc1ef8cd69`（tree `1252533ab3835d755225e22a3067a04296338c82`）。#369/#370 は基準版に反映済み、#362 の優先度試行と #371 の請求読取ログは変更対象外。

## 表示の意味

- 車両分析の「同型式車との比較」に、開閉できる「部品別交換登録」を追加する。
- 現行の同一会社・型式・初度登録年・有効状態・集計期間の条件をそのまま使用し、自車を除く比較台数を併記する。
- 既存 `part_statistics` の登録件数と登録のある車両数を表示する。件数は同一車両・同一整備記録・同一部品を1件とする既存定義であり、数量や車両数と混同しない。
- 品番未登録、統合前の登録名称、実際の登録がない場合を区別する。全行を表示し、任意の件数で切り捨てない。
- 比較対象なし／初度登録年不明と、比較対象はあるが期間内に集計可能な登録がない状態を区別する。
- 登録内容の真偽、作業完了、故障原因は判定しない。件数から故障率・推奨交換時期を導かない。未登録は未交換の証拠ではない。
- 交換間隔の中央値・別々の日数/距離母数は今回表示しない。既存集計、AI、優先度、保存値、権限、DB/schema、依存、起動・本番設定の変更はない。

## 検証

専用Python試験は実Flaskと専用一時SQLiteを使用し、件数/数量/台数の区別、会社・車両・型式・年・無効・期間・親記録・架空資料除外、条件の往復、0/不明、14行、エスケープ、既存閲覧境界、保存値不変を確認する。

`tests/peer_part_statistics_browser/run-isolated.sh` は既存ガードを再利用する。新規HOME/TMP・認証情報を継承しない環境・一時SQLiteのみ・Python外部通信禁止・ブラウザは同originのGETだけを実Flaskへ橋渡しする。実AI/通知の外部配送や本番アクセスは行わない。既存通知GETの限定的な一時DB書込を区別し、部品・AI保存値の不変を検査する。

ブラウザ受入は厳密なhead SHAとclean treeを検査し、6画面幅、全行・末尾列、長い名称、クリック/キーボード開閉、条件/期間フォーム、戻る/進む、再読込、JavaScriptなしを確認する。ローカルpreflightは描画受入の代わりではない。GitHubの当該headのCIとartifactを結果の根拠にする。

ローカル検証例（固定依存のPythonを指定）:

```sh
PYTHONPATH=.:tests python -m unittest test_peer_part_statistics_display -v
bash tests/peer_part_statistics_browser/run-isolated.sh "$PWD" /absolute/venv/bin/python --expected-sha "$(git rev-parse HEAD)" --preflight-only
```

全体回帰は既存 `regression-tests.yml`、実ブラウザは追加の `peer-part-statistics-browser.yml`。この文書自体は未実行のチェックを合格と宣言しない。マージ・本番反映は別承認。
