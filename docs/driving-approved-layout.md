# 運転実績：承認画像への画面調整（2026-10-27）

基準は提示された本人画面の上下2枚と仕様書v0.21のF093・K21～K40。main 68f304b（PR #206・#207統合済み）から変更した。

- 見出しと通知・プロフィールを同じ行へ置き、期間・比較期間・範囲・出力をコンパクトなツールバーに集約。
- AIは横3列から縦3段へ変更。ラベル、結論、数値と根拠を揃え、詳細根拠は展開する。増減の色と表現は確定集計に基づき、安全改善・個人責任の認定には使わない。
- 指標は横3枚、カテゴリ切替、共通の条件・出典表示。推移は全幅の青い折れ線と目盛、比較線を使い、欠損は線を切る。
- 本人・個人詳細の次回確認は全幅に配置。車両履歴・本人設定・対応履歴・根拠日報は折りたたむ。一般利用者の権限は既存処理を維持。
- 管理者の範囲全体でも日別の分子・分母を集計して推移を表示。営業所・会社・個人・出力の条件を引き継ぐ。
- 共有テンプレートには任意の見出しブロックだけ追加。ページ固有のCSSはheadから読み込み、他画面へ適用しない。

画像の件数・氏名・数値を本番へ入れる変更はしない。日報のない範囲では空の理由と期間変更導線を示し、グラフ・AI結論・0点を作らない。最低記録量・実資料の測定条件は引き続きU40の業務受入事項。

隔離SQLiteと有料AIを呼ばないブラウザ試験で、本人・営業所・会社・個人、カテゴリ・条件・戻り先・原本への権限・折りたたみを検証する。PCと320/390/430/768pxの表示確認は本番受入とは区別する。

## 2026-10-27 再修正：画面全体の順序を統一

利用者の「全く同じにして、すべて」という再指示と実画面を受け、管理者もAI、集計行、前期間比較、日別推移、次の振り返りを主表示にする。営業所・乗務員一覧は下部の展開操作に移し、会社／営業所／個人への既存導線と戻り位置を維持する。初期範囲と会社境界は変更しない。これはv0.21の管理者画面順序への後続指示として記録する。

日報0件と、休憩・待機・距離等の原本値しかない場合も、比較・推移・次回確認のセクションを保持する。比較値なしのカードは「—／記録なし」、推移は理由のみとして、架空の点・線・評価を作らない。安全運転／経済運転の切替はデータなしでも維持し、取得済みの原本値は下部で参照できる。氏名一致による本人公開や、原本値を安全指標に変換する処理は追加しない。
