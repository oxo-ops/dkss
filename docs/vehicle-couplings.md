# 連結車両の紐づけ

車両カルテの基本情報欄に連結車両を登録する。登録対象は同じ会社の有効な車両。
営業所は限定せず、同じ営業所を候補の先頭にする。車番・車台番号・営業所・車種で検索できる。

- トラクタ／トレーラーヘッドとトレーラーの組合せに対応。
- フルトレーラーをけん引するトラックも対象。大型という区分だけではけん引適合性は判定できない。
- 車種と形状から候補を抽出する。明示されたセミ／フルの種別と異なる組合せは受け付けない。
- 車検証等で確認した組合せであることを登録者が確認して保存する。システムによる法的・機械的適合性の判定は行わない。
- 付け替え用に複数の組合せを登録でき、双方のカルテから相手へ移動できる。
- 管理者とITCが追加・解除でき、一般ユーザーは閲覧できる。操作は監査ログに残る。
- この関連付けは現在の連結状態や運行記録ではない。トレーラー間のドリーを含む連結順序の管理は対象外。
- 点検・整備・費用・走行距離・AI分析は車両ごとに保持する。紐づけによる距離のコピーや費用の合算はしない。
- 車両が無効化・車種変更された後も既存の紐づけは残り、確認・解除できる。

## 導入

既存DBに新しい `vehicle_coupling` テーブルを作るため、更新後に既存の設定を読み込める環境で次を実行し、Flaskを再起動する。

```powershell
py -m flask --app app init-vehicle-couplings
```

上記コマンドはこの機能のテーブルと索引のみ作成し、何度実行しても既存の紐づけは保持する。
GETリクエストでDDLは実行しない。初期化前でも既存カルテは閲覧でき、追加ボタンは登録準備中となる。
新規テーブルへの追加のみで、既存車両テーブルの変更や既存データの書き換えは行わない。

## 調査根拠

- 全日本トラック協会「事業用トラックの種類」：フルトレーラは単車にトレーラを連結し、けん引車は通常のトラックとしても使用できる。
  https://jta.or.jp/ippan/hayawakari/2-shurui-page1.html
- 国土交通省「トレーラおよびトラクタの連結仕様検討書」：車名・型式、車台番号、形状、寸法等で組合せを検討する。
  https://wwwtb.mlit.go.jp/kinki/content/000357982.pdf
