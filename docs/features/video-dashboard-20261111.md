# 動画に沿った安全・車両ダッシュボード

基準main: `e8a529e48be239e1acbebbab333fe6395fd061f3`。
対象資料: ALSEON_P7_short_93s_4K_revised.mp4 の終盤（85秒付近）、
ALSEON_video_UI_images.zip の06_dashboard.png、
2026-11-10仕様書の07章とK64。動画・原画は紹介用の架空データであり、
その氏名、車両番号、件数、日付、優先度を製品へ移していません。

## 直接対応

- 動画の「安全管理：次の対応」と「車両管理：AIの整備提案」を上部の
  同じ「安全・車両の確認・対応」領域へ配置します。安全は対策確認待ち、
  差し戻し、対策未確認を区別し、元記録の写真・対策・期限へ移動できます。
- mainに既にある車両提案の保存済み内容、使用車両/営業所の区分、5件プレビュー、
  残件展開、回答・優先度の算定は変更しません。共通優先度の変更は別作業です。
- 動画の営業所傾向から記録への導線を、従来の最多1項目/代表1記録だけでなく、
  各項目の該当記録へ展開します。件数は満点未満の回答数であり、
  安全リスクや対応優先度の順位ではありません。

## 集計・権限

実際の所属営業所と同一会社を使用します。保存済みの営業所設定から閲覧範囲を
広げません。安全項目は詳細画面と同じUUIDベースの閲覧権限を通してから表示・
集計します。営業所傾向の安全記録にも同じ判定を先に適用し、閲覧できない記録を
集計値や項目名から漏らしません。所属未設定は空表示です。

安全の未完了案件は期間で消さず「全期間」と明記し、Goodと承認済みは除外します。
最初の3件と残件展開は表示制御であり、件数を3件へ固定しません。
安全の表示は既存show_pending、車両/傾向はshow_analysisに従います。
既存の「あなたへの未対応指摘」は本人向け導線として保持します。
会社全体に閲覧範囲を広げる変更、モデル変更、マイグレーション、AI生成、
状態更新、通知送信、車両の運行判断、外部サービス接続は追加しません。
既存dashboard GETの利用状況更新まで読み取り専用と主張するものではありません。

## 検証

新規の一時SQLiteと架空記録で、会社/営業所/一般利用者UUID/旧未解決本人/
閲覧不可件数/空表示/展開/HTMLエスケープ/表示設定/元記録GET/安全原値保持を
検証します。既存ダッシュボード出力fixtureは、安全パネル追加と閲覧可能な
傾向・元記録の2項目だけ更新し、他の集計契約の変化を拒否しています。

ブラウザ検証は既存の隔離されたFlask GETブリッジとChromiumを使います。
1440/1180/900/768/390/320px、繰り返し展開、キーボード、Back/Forward、
傾向タブ、元記録、JavaScript無効時を確認し、画面画像を保存します。
実会社データ・本番ログイン・実端末受入・本番反映は含みません。
