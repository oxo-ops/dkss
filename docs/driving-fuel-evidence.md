# 重複日報の燃料量と燃費比較（2026年10月27日）

仕様書v0.21のF093・K24～K26・K33に対応する集計上の修正。同じ運行の日報が複数あり、燃料量が「10」と「10.0」、単位が「L」と「ℓ」の場合、従来は文字列の違いにより燃費が集計されず、確認理由も表示されなかった。異なる燃料量についても同様に理由が表示されていなかった。

- 明記された消費燃料を数値で照合し、L・l・ℓ・リットルと全角表記の等価性だけを扱う。同量・同条件の複製日報は運行・距離・消費量を一度だけ計上する。原文の文字列と単位は更新しない。
- 燃料量と単位は同じ日報に記載されているものを対として確認する。量だけの複製と単位だけの複製を継ぎ合わせて新しい根拠にしない。未記載、0、負数、非数値、非L単位は燃費の分母へ採用せず、単位換算や燃費からの逆算を行わない。燃料量の記載自体がない日報へ新しい入力を要求しない。
- 同じ運行の消費量・提供元・設定版・集計粒度に不一致がある場合、燃費を保留する。他の取得済み指標や確定距離は保持する。対象範囲の関係日報それぞれへ確認理由を出し、既存の日報訂正画面から原本を確認できるようにする。
- 違う運行でも、記載された設定版が異なる燃費は別の指標として扱い、設定版を表示する。版の情報がないことを埋めるために専門項目を必須入力へ追加しない。実帳票での測定定義・対象期間・最低記録量の業務確認はU40で継続する。
- 燃費は引き続き有効な対象距離の合計÷対応する消費燃料の合計で算出する。100km・10Lと300km・20Lなら400÷30≒13.33km/Lとする。日別燃費の単純平均や、不一致の燃料を使ったAI説明は行わない。画面・比較CSV・AI根拠は同じ採用値・対象範囲を使う。

検証：`test_driving_fuel_evidence.py`で表記差、重複、量の不一致、別日報からの単位借用の拒否、0・非数値・非L単位、設定版の分離、画面・CSV・AIと会社境界を確認する。ブラウザで二つの対象日報への確認導線、本人範囲、320/390/430pxを確認する。DB定義・本番データ・有料APIは変更しない。
