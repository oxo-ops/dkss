# レップの指摘と全体構造の対応

会議の「app.pyへの機能集中」「目的ごとの分割」「UI・出力・設計思想の継承」
に対し、個別の関数抽出から、アプリ全体の起動・DB・登録・処理の境界を
組み替える改修へ進めた。現在の構成・起動手順・検証結果は
[application_architecture.md](application_architecture.md) を参照。

| 指摘 | 対応 | 残る検証 |
| --- | --- | --- |
| app.pyの集中、目的ごとの管理 | 全業務領域を責務別モジュールへ配置。factory、extensions、models、routes、databaseを分離 | 長い個別業務フローの設計改善は依然必要 |
| UI・出力・設計思想の継承 | テンプレート・CSS・JSを変更せず、URL・モデル・フックの契約を固定 | 実運用画面での確認 |
| 内部処理の棚卸し・軽量化 | 静的棚卸しをパッケージへ拡張。既存の重複SQL削減・日付変換改善を維持 | OCR・AI・待ち行列・本番同時負荷の実測 |
| 小さな修正もPRレビュー | 回帰CI・契約テストを保持し、全体変更を一つのPRで確認可能にする | 人による設計・運用レビュー |
| セキュリティと負荷 | 会社境界・認可・同時更新等の既存回帰テストを維持 | 認証済み動的検証、実際の同時利用条件の合意と負荷試験 |
| ER図・定義の共有 | 全57テーブルのモデル定義・索引を変更前と比較できる契約を保存 | 本番スキーマとの照合、tblsによる更新運用 |

完了の判定はファイル数やapp.pyの行数ではなく、起動でDBを書き換えないこと、
依存先を明示できること、アプリ間で状態が混ざらないこと、既存の業務契約を
保てることで行う。構造改善と性能・セキュリティの検証はそれぞれ根拠を記録する。


## 2026-10-26: 共通ポリシーとCSSの整理

10/23会議の文字起こしを確認し、指摘と今回の変更を区別した。

- 間野さん 5:44–6:15、13:34: app.pyへの集中を解き、目的別のコンポーネント・クラスで管理する。
- 間野さん 26:24–27:38: UI・出力・設計思想を引き継ぎ、利用者が増える前に全体を見直す。
- 桑田さん 25:32–26:17: AIを含む内部処理を棚卸しし、分割・軽量化する。
- 間野さん 17:39: 外販前にセキュリティと負荷を検証する。
- 間野さん 32:34: 小さな修正もPRでレビューする体制を作る。
- 間野さん 34:24–36:05: ER図を共有する。DBカラムの説明コメントはtblsで資料に抽出できる。

文字起こしに「コードのコメントをすべて消す」「CSSを一つにまとめる」という指摘はない。
今回のコメント・CSS整理は、上記の保守性向上に対する実装上の対応である。

| 対象 | 変更 | 維持する契約 |
| --- | --- | --- |
| 点検・交換基準の時期計算 | `maintenance_timing.AdoptedMaintenanceTimingService`へ移動し、厳密な値検証・距離・暦の計算を共通化 | 点検証拠と交換証拠を混同しない。保留理由・根拠ID・出力フィールドを維持 |
| 承認・差戻し | `can_reject_checklist_result`も既存の承認権限ポリシーを使用 | 同会社境界、管理者、一般承認設定の既存条件 |
| Excel帳票 | `report_layout.spreadsheet_text_width`を2つの帳票で使用 | 全角文字の幅・行高・帳票の寸法 |
| CSS | 同条件・同セレクタの重複指定23件を除去し、隣接する同一宣言5組を共通化 | セレクタ詳細度・条件・適用順。ブラウザ固有疑似要素はまとめない |
| コメント | 装飾罫線だけのPythonコメント146行を削除し、CSSの一時版番号を用途の説明に置換 | 業務ルール、会社境界、例外理由、ライセンス・ツール指示などの説明 |
| 旧作業用スクリプト | 未参照の`run_saved_analysis_worker.py`を削除 | 正式な分析ワーカー・ジョブ処理は維持 |

`style.css`には依然として多数の画面・レスポンシブ・状態別ルールがある。
行数だけを理由に未使用と判定したり、別画面のルールを無条件に統合したりしない。
CSSの大規模な再配置は、共通部品と画面専用ルールの所有範囲を決めた上で、
実画面の状態・幅ごとに検証する別の変更として扱う。

今回の計算共通化はローカル処理の整理であり、AI API待ち時間の短縮や本番200名の
同時利用能力を立証するものではない。上表以外の残る運用検証は引き続き必要。

検証結果: 全366テスト成功（既存359件＋時期判定7件）。旧実装と新実装の
時期判定出力は2,304ケース、差戻し権限は64ケースで一致した。
CSSは全9ファイルについてセレクタ・メディア/サポート条件・プロパティ・優先度別の
最終指定値と解析エラーが変更前後で一致した。実ブラウザの画面比較は未実施。
