# 運転実績：仕様書 v0.25 との差の解消

対象は仕様書23〜25・30〜32ページ、K32・K39・K43・K44・K47・K53。照合時mainは `f0ad512`、実装の起点は後続の `0d40cea`。

## 本人集計の保留

日常点検の原実施者・対象日・車両と一致する最新の任意訂正が「乗っていない」、又は元の車両から「別の車両」への変更で、その本人の同日・元車両の日報がある場合、その運行の本人集計を保留する。根拠が変更された旧訂正、別会社・別本人・別日・別車両へは適用しない。

本人の運行数・距離・指標・推移・乗務車両・個人比較・AI入力には加算しない。管理画面の個人別集計も同じ保留を適用する。会社・営業所・車両側の運行記録と全体集計、原本、本人特定と閲覧権限は変更しない。日報自体は従来の権限で閲覧できる。画面と原本値CSVに保留理由を示し、比較CSVには保留運行数を付ける。PDFも本人の比較集計から除外し、保留中の日報を原本値として区別する。候補訂正の取消・再訂正は既存操作で行い、次の読取時に再評価する。通常GETで保存や有料AI実行を追加しない。

訂正の読取は会社内で1リクエスト中に再利用する。管理概要のSELECT上限はこの根拠照合の1回分を追加し、会社・アカウントを越えるキャッシュは作らない。

## 一覧への復帰

乗務員行・日報行に安定したIDを持たせ、詳細を開く際に元の条件・行の画面内位置・折り畳み状態をタブ内に控える。個人画面で指標を変更しても、一覧へ戻る操作は元の条件と行に戻る。日報詳細の戻り先も同じ元条件を使う。控えは同一会社・アカウント・ロールと同一画面に限定し、30分・最大12件、復帰時に消費する。控えを権限判定には使用しない。Ctrlクリック・別タブ・出力・外部リンクの動作は維持する。

## 管理概要の順序

会社・営業所の概要は、基本条件、AI、集計行、指標、開いた営業所／乗務員一覧の順に表示する。概要に個人向けの日別推移・空の次の振り返りを置かない。個人詳細と自分の実績では日別推移・次の振り返りを維持する。日報・比較条件・原本値等の補助表示も維持する。

## 検証範囲

- 隔離SQLite：本人保留、訂正取消、同日の複数車両、別日・別アカウント、根拠変更、会社全体値の保持、個人比較、原本値CSV・比較CSV、原本保持と閲覧、AI入力の無効化。
- 実アプリのHTMLとローカルChromium：幅320／390／430／768／1390pxで管理概要の順序・一覧の初期展開、指標切替、個人詳細内の指標変更後の復帰、日報詳細からの復帰、開閉状態、本人画面、横はみ出しを確認。
- 指標切替は文書スクロールとmain内スクロールでも回帰確認。

本番DB・WORLEX実資料・有料AI生成の受入完了を意味しない。適用スクリプトは隔離worktreeでパッチ適用・日報関連テスト・コミットを行い、push・マージ・デプロイは行わない。
