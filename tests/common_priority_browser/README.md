The workflow checks out the exact PR head and requires a clean matching commit. It installs the repository requirements and Playwright 1.62.0 in a new hosted-runner virtual environment. It has read-only GitHub permissions, no secrets, no deploy, and no production access.

Synthetic scoped daily-inspection records and their server-generated provenance flow through the ordinary result API. The fixture includes one strictly bound standard brake finding and saved legacy proposals, without changing an operation judgment through the UI. Stop-related and repair/recheck cases keep their saved label without a new score in this first integration stage. Real Chromium visits overview, analysis, and dashboard at 1440/1024/768/390/320px. Tests verify the server's order, numeric 50-point safety finding, legacy labels without invented scores, null-axis details and separate evidence explanation, repeated detail opening/closing, Escape and Back/Forward, plus contained horizontal layout. Screenshots and a JSON receipt are uploaded.

Requests to the exact synthetic loopback origin are fulfilled in-process by Flask's authenticated test client. There is no HTTP listener. Only GET is allowed; other methods/origins fail. Python network connections and SQLite outside a new disposable root are blocked. Environment and HOME are cleared before fixture creation. Existing notification maintenance and dashboard usage-summary writes in the temporary DB are separately listed; saved analysis, original inspection/judgment, feedback/evaluation and notification rows must remain unchanged. No live authentication, TLS transport, actual AI generation, actual repair, broad manufacturer timing or expert approval is certified by this test.

Use `run-isolated.sh ABSOLUTE_REPO ABSOLUTE_PYTHON --expected-sha SHA --preflight-only` for local fixture checks. A preflight success explicitly says `PREFLIGHT_PASS_BROWSER_NOT_RUN`. `--run-browser --chromium PATH` is for an authorized installed browser; do not retry a known local OS restriction. The hosted CI is the browser execution route for this candidate.
