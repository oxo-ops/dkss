Japanese report font derived from Noto Sans JP regular (Google Inc., SIL OFL 1.1).
The upstream Unicode subsets were merged and the family renamed DKSS Report Sans JP.
report-japanese.zip contains the TrueType font and its precomputed Unicode/glyph metrics.
The font is embedded in PDF exports; no client or server font installation is required.
Font license: OFL.txt. Source package: @fontsource/noto-sans-jp.
